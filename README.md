# cyns-thinkpad-project
hi i'm cyn :>! i'm rebuilding my thinkpad 760ED with framework internals! i have no experience with CAD, 3D printing, PCB design but it's best to aim high :> i'm going to document my learning process as best I can!


<b>initial concept :D</b>

in july i was looking for a way to access weather balloon data and found SondeHub Tracker, which relies on users of <a href=https://github.com/projecthorus/radiosonde_auto_rx/wiki>Radiosonde AutoRX</a> to track and receive broadcasts from radiosondes. Upon reading about the setup requirements, I set out to come up with a design for one myself.

Initially I was opposed to using a raspberry pi for this purpose and wanted to design a cyberdeck-esque device that was portable, which I could bring with me when tracking and hoping to collect weather balloons. It needed simply to run linux.

I floated the idea of building a tablet-like device with either a touchscreen LCD or making use of a trackball & mini-keyboard setup

then i decided to apply for university!
